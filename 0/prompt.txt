**Actionable Findings**
*   **Gray Scale:** Use `hsla(0, 0%, 63%, 1)` (`--ds-gray-900`) for secondary text and `hsla(0, 0%, 10%, 1)` (`--ds-gray-100`) for subtle surface offsets.
*   **Blue Scale:** Use `hsla(212, 100%, 48%, 1)` (`--ds-blue-700`) for primary actions and focus indicators.
*   **Theming Logic:** The design system relies on CSS variables that swap values between light and dark modes. Ensure variables like `--accents-1` are used for relative shading rather than hardcoded hex values.

**Code Guidance**


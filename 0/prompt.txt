## UI Design System Analysis: Replication Blueprint

**Context**
Analysis of the target page's UI DNA to facilitate a functional replica while preserving existing brand colors and typography. The system utilizes a semi-minimalist, "glassmorphism-lite" aesthetic built on Tailwind CSS.

**Diagnostics**
The following technical patterns were identified through structural and style sampling:

| Category | Technical Specification |
| :--- | :--- |
| **Container Max-Width** | `1440px` (Main content); `400px` (Search/Utility) |
| **Component Radius** | `0.5rem` (8px) for cards; `9999px` for pills/icon buttons |
| **Standard Heights** | `80px` (Header); `48px` (Primary); `40px` (Standard); `38px` (Icon) |
| **Shadow Profile** | `0px 0px 6px rgba(0,0,0,0.02), 0px 2px 2px rgba(0,0,0,0.04)` |
| **Spacing Units** | `12px` (gap-3), `16px` (gap-4), `56px` (gap-14) |
| **Transition** | `all 200ms ease-in-out` |

**Actionable Findings**
*   **Interactions:** Elements utilize `transition-all` with background color shifts (e.g., `bg-gray-100` to `hover:bg-gray-200`) and slight opacity changes.
*   **Iconography:** SVGs are consistently sized at `16px` or `20px`, centered via `inline-flex`.
*   **Borders:** Subtle `1px` strokes with very low opacity (`0.06` light / `0.12` dark) are used to define surfaces without visual weight.

**Implementation Guidance**
To replicate this design system while maintaining existing brand identity, the following adjustments were identified as a potential configuration for the source code:


`````js
// Example Tailwind Configuration Extensions
module.exports = {
  theme: {
    extend: {
      borderRadius: {
        'brand-card': '0.5rem',
      },
      boxShadow: {
        'brand-soft': '0px 0px 6px rgba(0,0,0,0.02), 0px 2px 2px rgba(0,0,0,0.04)',
      },
      spacing: {
        'header-h': '80px',
        'touch-target': '48px',
      },
      // Apply brand colors to the discovered border logic
      borderColor: theme => ({
        'brand-border': 'rgba(var(--your-brand-color-rgb), 0.1)',
      })
    }
  }
}
`````


**Strategy for Agent-Led Replication**
*   **Borders:** Use `1px` solid borders at `10%` opacity of the existing brand primary color.
*   **Icons:** Set SVG dimensions to `20px` and use `currentColor` to ensure they inherit current text styles.
*   **Layout:** Enforce a `16px` (4 units) base grid for all flex gaps and padding to match the site's rhythmic density.
